# Note-Library

Welcome to my Note Library!

本项目分享了本人在中山大学计算机学院就读期间的部分学习笔记，以及一些我自己拓展学习的知识笔记。

本项目为非营利、免费的开源项目，旨在为学弟学妹们提供免费的笔记资源，降低学习成本，提高学习效率。同学们可以自行取阅，但转发分享时请注明出处，谢谢你的配合！

希望本项目能对你们的学习提供帮助，如果喜欢希望能给个star🌟

## 前言

简单谈一下为什么我要建立 **Note-Library** 这个项目。

自从高中以来，我就很喜欢整理自己的笔记，记录自己对知识的理解，以便自己查阅和复习。但是以前我一直处于一个很保守的状态——不想分享自己的笔记，害怕别人会抄袭我的笔记内容。直到上了大学，才慢慢发现，开源世界的美好，不仅仅能够帮助他人，还能在这个分享的过程中获得他人的认可，从而产生成就感。因此，我将我的笔记开源，建立了 **Note-Library**。

在我大三这年准备期末考试之时，一段备考数据库的经历令我更深刻地明白了分享笔记的意义。当时，我的数据库老师讲课讲得并不是很好，书上也写得不是很清楚。正当我为如何备考而焦虑时，我找到了一份往年学长学姐整理的数据库笔记，里面的内容详细清晰，涵盖了主要的知识点，语言也很简单直白，避免了原书机译的晦涩难懂。在这份笔记的帮助下，我用大约3天时间，结合着书本内容，理解清楚了要考的知识点，并且整理出一份自己的笔记。经过紧张的复习，在最后的期末考试中，取得了一个较好的成绩。假如没有这份笔记，我恐怕还在艰难地啃书，复习效率十分低下，恐怕我最后也难以考到一个较好的成绩。

这段经历让我看到了：前人整理的笔记，能够方便后人复习，后人也能在前人笔记的基础上做出进一步的整理或拓展笔记中的内容，造福再下一代的人。俗语有云“*前人种树，后人乘凉*”，我想这便是笔记分享的更深刻的意义——“**传承**”。如果我没有将笔记分享出去，那么我的笔记在我复习完之后就会进入“长眠”，也许很久之后会再拿出来翻一下，但是这个很久之后是多久？无人知晓，我的笔记可能就会一直这样沉睡下去，既浪费了存储空间，也浪费了我当初整理笔记的心血。而如果我将笔记分享给别人，别人就能够看着我的笔记来整理和复习，避免了重复的整理，提升学习效率，让我的笔记不断产生新的价值，这不是更加有意义吗？

这次经历坚定了我要分享笔记的决心，于是便有了这个 **Note-Library**

当然，我希望准备/正在使用这份笔记的你不仅做“乘凉的后人”，还要做“种树的前人”。如果你在这份笔记的基础上进行了进一步的整理或拓展了其中的内容，我希望你也能开源分享出去，或者通过Pull request的方式上传到本仓库。“*前人种树，后人乘凉*”，“*赠人玫瑰，手有余香*”，我相信你也将会在分享笔记的过程中不仅享受到成就感，还享受到更深刻的“传承”的意义。

我将会万分感激你的分享与贡献！❤
